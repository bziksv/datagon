Медмаркет

Страница /medmarket.html — стыковка позиций МойСклад с кодом товара для Медмаркета. Карта: Карта панели. API: /api/medmarket → routes/medmarket.js.

Ключ строки: код МС + тип (товар | комплект | услуга). Тип из ms_export.type (lib/datagonMedmarketType.js). Каноническая связка: код+Тип (как в Motion), напр. 10088+Товар → поле ms_export.medmarket_product_code.

Доступ​

Ключ матрицы — medmarket.

РежимЧто доступно
hiddenHTML и /api/medmarket недоступны
viewСписок / sync-status — GET
fullsync, PATCH mapping, import, fill-linkage-codes

Колонки​

КолонкаИсточник
Кодms_export.code
Наименованиеms_export.name
Типнормализованный тип МС
Код товара для медмаркетасвязка код+Тип. Пустая ячейка + серая подсказка «ожидается: …» — не стыковка

Действия​

  • Применить — фильтры (код, имя, тип, код Медмаркета, Стыковка = есть валидная связка код+тип, не просто непустое поле). Только по кнопке / Enter.
  • Подтянуть из карточек МС — атрибут из ms_entity_details.payload_json → ms_export (POST /sync / import; без перезаписи уже заполненных; чанк ~6000).
  • Заполнить коды в МойСклад — по применённым фильтрам пишет канон в атрибут МС и БД (POST /fill-linkage-codes). Сначала dry_run, затем запись. Журнал #mm-action-log: фильтры, счётчики, ошибки МС (не одна строка «идёт…»).
  • Правка ячейки → PATCH /mapping.

Автосинхронизация​

На Настройках, блок «Экспорт в МС»:

ЗадачаЧто делаетРекомендуемые дни (МСК)
medmarketИмпорт атрибута → ms_export (без записи в МС)только вс, 09:00
medmarket_fillКак «Заполнить коды…» без фильтров (~10–12 тыс. правок, остальные skip)пн–сб, 09:30

Журнал — Активность / Логи, task_type medmarket / medmarket_fill.

Связь​

Зависит от актуального МойСклад (ms_export + ms_entity_details). Не путать с синком каталога moysklad.
