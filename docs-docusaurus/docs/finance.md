Страница **`/finance.html`** показывает **балансы** и **проводки** банка **Точка**. Это только чтение: исходящие платежи, вебхуки и Райффайзен в этом релизе не подключены.

## Доступ

Ключ матрицы специальностей — **`finance`**.

- **`full`** — JWT, «Проверить связь», «Обновить из банка», расписание автосинка.
- **`view`** — карточки остатков и таблица движения; поле токена скрыто.
- **`hidden`** — страница и `/api/finance` недоступны.

## JWT

В кабинете Точки: **Интеграции и API** → скопируйте **JWT** (длинный Bearer-токен) в поле на `/finance.html`.

**Client ID** и **Client Secret** в Datagon **не используются** (это поля OAuth-приложения в кабинете Точки). Redirect URL тоже не нужен.

Нужные scopes: **ReadAccounts**, **ReadBalances**, **ReadStatements**.

Ключ сохраняется в `app_settings.finance_tochka_jwt` через `POST /api/finance/config`. В общем `GET /api/settings` его нет: в ответах списка только маска вида `kKxJ…7y2Q (N симв.)`.

## Что делает синк

Кнопка **«Обновить из банка»** (и опционально автосинк `finance_tochka`):

1. `GET /open-banking/v1.0/accounts`
2. для каждого счёта — балансы (`ClosingAvailable` / `Expected`)
3. Init Statement + ожидание Ready, проводки пишутся в `dg_finance_tx`

Экран читает **снимок из БД**, не Точку на каждый фильтр. Период выписки — 1…90 дней (по умолчанию 30).

Таблица **«Движение»**: поиск, даты, входящие/исходящие, счёт; пагинация «Найдено / страница / показано», 100 строк по умолчанию.

Расписание (выкл. по умолчанию) — карточка на `/settings.html`, журнал — `/processes.html` (`task_type=finance_tochka`).
