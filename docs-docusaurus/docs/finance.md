Страница **`/finance.html`** показывает **балансы** и **проводки** банка **Точка**. Это только чтение: исходящие платежи, вебхуки и Райффайзен в этом релизе не подключены.

## Доступ

Ключ матрицы специальностей — **`finance`**.

- **`full`** — JWT, «Проверить связь», «Обновить из банка», расписание автосинка.
- **`view`** — карточки остатков и таблица движения; поле токена скрыто.
- **`hidden`** — страница и `/api/finance` недоступны.

## JWT (несколько организаций)

На `/finance.html` можно сохранить **несколько JWT** — по одному на организацию (или один ключ с правами на все компании).

Хранение: `app_settings.finance_tochka_credentials` (JSON-массив `{ id, label, jwt, enabled, customer_codes, customer_names }`). Старый одиночный ключ `finance_tochka_jwt` при первом чтении **мигрирует** в первую запись списка и дальше дублирует JWT первого включённого ключа (back-compat).

Колонка **«Организация»** — ручное `label` (или авто из первого ООО в клиентах JWT, без склейки «ООО · ИП»). Колонка **«Клиенты»** показывает всех `customer_names` по ключу (у одного JWT в кабинете Точки может быть несколько юрлиц).

Кнопка **«Загрузить выписки»** в фильтрах тянет проводки из Точки с учётом **дат / организации / счёта** (без дат — окно «Выписка, дн.»). **«Обновить все»** — полный синк всех включённых JWT. У каждой строки в «Настройки банка» есть **«Обновить»** — только этот JWT.

TLS к `enter.tochka.com` — через CA Минцифры (`certs/russian-trusted-ca-bundle.pem`). **Client ID** / **Client Secret** не используются.

В общем `GET /api/settings` JWT нет — только маски через `/api/finance/config`.

## Что делает синк

Кнопка **«Обновить из банка»** (и опционально автосинк `finance_tochka`):

1. `GET /open-banking/v1.0/accounts` (+ `customers` для подписи организации)
2. `GET /open-banking/v1.0/balances` (остатки по всем счетам одним запросом)
3. Init Statement + ожидание Ready, проводки пишутся в `dg_finance_tx`  
   (ответ Get Statement часто отдаёт `Data.Statement` **массивом** — клиент разворачивает первый элемент; иначе статус Ready не виден и выписка «висит»)

Экран читает **снимок из БД**, не Точку на каждый фильтр. Период выписки — 1…1095 дней (~3 года; по умолчанию 30).

**Ограничение API: депозиты и фонды**

В Open Banking Точки нет отдельных endpoint’ов для фондов. На карточках счетов можно вручную:

- поставить флаг **«Фонд»**;
- задать **своё название** (`custom_name`).

Поля хранятся в `dg_finance_accounts` (`is_fund`, `custom_name`) и **не затираются** синком из банка. В фильтре «Счёт» и в таблице движения отображается custom_name, если задано.

Практика по текущему JWT: API часто отдаёт только `CurrentAccount`; нужные «фонды» в интернет-банке помечайте на карточках вручную.

**Названия организаций** (карандаш на шапке блока счетов): **полное** и **короткое** в `app_settings.finance_org_aliases`.
- **Короткое** — на карточках балансов.
- **Полное** — в фильтре «Организация», колонке «Движение», аналитике и поиске.

Таблица **«Движение»**: колонка **«Организация»** — полное имя (alias `full`, иначе `org_label` из банка). Операции внутреннего оборота (депозит UNV, перевод своих, дивиденды) помечены бейджем **«не в графике»** (видны при включённой галке внутренних). Поиск, даты, входящие/исходящие, счёт; пагинация «Найдено / страница / показано», 100 строк по умолчанию. Галка **«Показывать депозиты, фонды и дивиденды»** (фильтры) — по умолчанию выкл.: в таблице и аналитике скрыты тело депозита UNV, «Перевод собственных средств» и **«Выплата дивидендов»**; проценты и платежи из фонда (налоги и т.п.) видны.

Карточка **«Аналитика по месяцам»**: KPI и график Chart.js по `dg_finance_tx` (6 / 12 / 24 мес.). Фильтры организации и счёта. **По умолчанию без внутреннего оборота:** тело депозита (открытие / возврат UNV), **«Перевод собственных средств»** (расчётный ↔ фонд) и **«Выплата дивидендов»**. Проценты по депозиту и платежи из фонда (налоги и т.п.) остаются. Галка «включая внутренние» / «Показывать депозиты, фонды и дивиденды» возвращает полный банковский оборот.

Карточка **«Контрагенты»** (под фильтрами): топ доходных («кто платит нам») и расходных («кому платим мы») с долей от суммы. Период / орг / счёт — из **применённых** фильтров; без дат — окно как у графика (`months`). Клик по строке подставляет поиск и направление — дальше «Применить».

Расписание (выкл. по умолчанию) — карточка на `/settings.html`, журнал — `/processes.html` (`task_type=finance_tochka`). Задача идёт на **воркер 2** (`parser-autosync-w2`), параллельно общей очереди МС на воркере 1.
