Страница **`/finance.html`** показывает **балансы** и **проводки** банков **Точка** и **Райффайзен**. Только чтение: исходящие платежи и вебхуки не вызываются.

## Доступ

Ключ матрицы специальностей — **`finance`**.

- **`full`** — ключи банков, «Проверить связь», «Обновить из банка», расписание автосинка.
- **`view`** — карточки остатков и таблица движения; поля токенов скрыты.
- **`hidden`** — страница и `/api/finance` недоступны.

## JWT Точки (несколько организаций)

На `/finance.html` можно сохранить **несколько JWT** — по одному на организацию (или один ключ с правами на все компании).

Хранение: `app_settings.finance_tochka_credentials` (JSON-массив `{ id, label, jwt, enabled, customer_codes, customer_names }`). Старый одиночный ключ `finance_tochka_jwt` при первом чтении **мигрирует** в первую запись списка и дальше дублирует JWT первого включённого ключа (back-compat).

Колонка **«Организация»** — ручное `label` (или авто из первого ООО в клиентах JWT, без склейки «ООО · ИП»). Колонка **«Клиенты»** показывает всех `customer_names` по ключу (у одного JWT в кабинете Точки может быть несколько юрлиц).

TLS к `enter.tochka.com` — через CA Минцифры (`certs/russian-trusted-ca-bundle.pem`). **Client ID** / **Client Secret** не используются.

В общем `GET /api/settings` JWT и ключи Райфа **нет** — только маски через `/api/finance/config`.

## Райффайзен (Open API)

Карточка «Настройки банка» на `/finance.html`: `client_id`, `client_secret`, `refresh_token` из RBO (**Интеграция банка с учетными системами** → API-оркестратор → «Выпустить Refresh-токен»).

Хранение: `app_settings.finance_raiffeisen_credentials`. Datagon сам обменивает refresh на `access_token` + `id_token` (`POST https://sso.rbo.raiffeisen.ru/token`) и **записывает новый refresh** (банк его ротирует).

Синк (только чтение):

1. `GET /api/v1/accounts`
2. Итоговые выписки и операции `GET /api/v1/accounts/{n}/statements` + `GET /api/v1/statement/transactions` (за текущий день — `/intraday`)
3. Счета и проводки в те же `dg_finance_accounts` / `dg_finance_tx` с `bank='raiffeisen'`

Банк может требовать **белый список IP** интеграции. Ошибки SSO/API видны в «Проверить Райф» и журнале синка.

Кнопка **«Загрузить выписки»** / **«Обновить все»** тянет **оба** банка (если ключи включены). У строки Райфа — только этот ключ.

## Что делает синк

Кнопка **«Обновить все»** (и опционально автосинк `finance_tochka`):

1. Точка: `GET /open-banking/v1.0/accounts` (+ `customers`) → балансы → Statement
2. Райф: счета + выписки за окно дат
3. Экран читает **снимок из БД**

Период выписки — 1…1095 дней (~3 года; по умолчанию 30).

**Ограничение API: депозиты и фонды**

В Open Banking Точки нет отдельных endpoint’ов для фондов. На карточках счетов можно вручную:

- карандаш / клик по названию → поле имени и галка **«Фонд»** (то же, что клик по бейджу типа);
- задать **своё название** (`custom_name`).

Поля хранятся в `dg_finance_accounts` (`is_fund`, `custom_name`) и **не затираются** синком из банка. В фильтре «Счёт» и в таблице движения отображается custom_name, если задано.

Практика по текущему JWT: API часто отдаёт только `CurrentAccount`; нужные «фонды» в интернет-банке помечайте на карточках вручную.

**Названия организаций** (карандаш на шапке блока счетов): **полное** и **короткое** в `app_settings.finance_org_aliases`.
- **Короткое** — на карточках балансов.
- **Полное** — в фильтре «Организация», колонке «Движение», аналитике и поиске.

Таблица **«Движение»**: колонка **«Организация»** — полное имя; колонка **«Банк»** — Точка / Райффайзен. Операции внутреннего оборота (депозит UNV, перевод своих, дивиденды) помечены бейджем **«не в графике»** (видны при включённой галке внутренних). Поиск, даты, входящие/исходящие, счёт; пагинация «Найдено / страница / показано», 100 строк по умолчанию. Галка **«Показывать депозиты, фонды и дивиденды»** (фильтры) — по умолчанию выкл.: в таблице и аналитике скрыты тело депозита UNV, «Перевод собственных средств» и **«Выплата дивидендов»**; проценты и платежи из фонда (налоги и т.п.) видны.

Карточка **«Аналитика по месяцам»**: KPI и график Chart.js по `dg_finance_tx` (6 / 12 / 24 мес.). Фильтры организации и счёта. В ячейке **«Чистый поток»** — сумма за окно, **средний месяц** по полным месяцам (текущий недописанный не входит) и **динамика последнего полного месяца к предыдущему** (подписи месяцев). **По умолчанию без внутреннего оборота.**

Карточка **«Контрагенты»** (под фильтрами): топ доходных («кто платит нам») и расходных («кому платим мы») с долей от суммы. Период / орг / счёт — из **применённых** фильтров; без дат — окно как у графика (`months`). Клик по строке подставляет поиск и направление — дальше «Применить».

Расписание (выкл. по умолчанию) — карточка на `/settings.html`, журнал — `/processes.html` (`task_type=finance_tochka`). Задача идёт на **воркер 2** (`parser-autosync-w2`), параллельно общей очереди МС на воркере 1. Прогон включает включённые ключи Точки и Райфа.
