Страница **`/db-admin.html`** — админский обзор **основной** базы Datagon (не Bitrix/Webasyst из «Мои сайты»). В меню — с иконкой замка (`data-dg-nav-restricted="activity"`). Ключ матрицы: **`db-admin`**.

Карта меню: [Карта панели](/docs/panel-map/). HTTP: [REST API — Управление БД](/docs/api/#управление-бд).

## Кому доступно

Два независимых уровня:

1. **Пункт меню / HTML** — как «Активность/Логи»: виден и открывается только **`admin`** или пользователю с **`can_manage_users`**. Ключ матрицы `db-admin` участвует в общем реестре страниц, но замок меню завязан на manage-users, не только на `page_modes`.
2. **API `/api/db-admin/*`** — жёсткая проверка в `routes/dbAdmin.js`: иначе **403** («нужны администратор или право управления пользователями»). Даже при `db-admin=full` в матрице без `can_manage_users` API не отдаст данные.

## Что на экране

1. **Сводка базы** — имя схемы, объём всего / данные / индексы, число таблиц, полоска данных vs индексов; **Обновить** → `GET /api/db-admin/overview?refresh=1`.
2. **Связи с системами** (сворачиваемая карточка) — смысловые домены из `lib/datagonDbRelations.js` (`GET /relations`), не FK-граф MySQL.
3. **Таблицы** — список из overview (размеры и оценка строк `information_schema`):
   - фильтры **поиск** и **домен** — черновик до **Применить** (Enter в поиске = Применить; Esc — очистить и сразу применить); **По умолчанию** сбрасывает;
   - **На странице** (размер страницы) применяется сразу при смене (клиентская пагинация, по умолчанию **40**);
   - по строке: **Превью** (20 строк), **ANALYZE**, **OPTIMIZE** (своя confirm-модалка);
   - чекбоксы + **ANALYZE выбранные** / **OPTIMIZE выбранные** (до **40** таблиц за запрос);
   - журнал итогов — `#dg-dba-action-log` на карточке таблиц.

## API (кратко)

| Метод | Путь | Назначение |
|--------|------|------------|
| GET | `/api/db-admin/overview` | Сводка + `tables[]` |
| GET | `/api/db-admin/relations` | Каталог доменов |
| GET | `/api/db-admin/tables/:name/preview?limit=` | Превью (1…50, UI шлёт 20) |
| POST | `/api/db-admin/analyze` | `{ tables: [...] }` |
| POST | `/api/db-admin/optimize` | то же; может **блокировать** таблицу |

Имена таблиц только из текущей схемы — произвольный SQL запрещён.

## Чего нет (намеренно)

- Подключения к БД CMS сайтов;
- очистка по retention (карточки на `/settings.html`);
- SQL-консоль, DROP, ALTER.
