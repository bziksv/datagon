Страница **`/db-admin.html`** — админский обзор **основной** базы Datagon (не Bitrix/Webasyst сайтов из «Мои сайты»).

## Кому доступно

Как у «Активность/Логи»: пункт меню с замком; API отвечает **403**, если пользователь не `admin` и без флага `can_manage_users`. В матрице специальностей ключ страницы — **`db-admin`**.

## Что на экране

1. **Сводка** — имя БД, общий размер, данные vs индексы, число таблиц, кнопка «Обновить».
2. **Связи с системами** — смысловые группы (CMS, МойСклад, маркетплейсы, цены сети, парсер, закупки, финансы, журналы). Подписи из `lib/datagonDbRelations.js`, не FK-граф MySQL.
3. **Таблицы** — размеры и оценка строк из `information_schema`, фильтр/поиск по кнопке «Применить», пагинация. Действия:
   - **Превью** — до 20 строк + список колонок;
   - **ANALYZE** — пересчёт статистики оптимизатора;
   - **OPTIMIZE** — с подтверждением; может **надолго заблокировать** таблицу на боевой нагрузке.

Журнал массовых ANALYZE/OPTIMIZE — блок `#dg-dba-action-log` на карточке таблиц.

## API

См. [REST API — Управление БД](/docs/api/#управление-бд).

## Чего нет (намеренно)

- Подключения к БД CMS сайтов;
- Очистка по retention (это карточки на `/settings.html`);
- SQL-консоль, DROP, ALTER.
