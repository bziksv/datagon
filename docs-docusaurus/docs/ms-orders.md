Страница **`/ms-orders.html`** — заказы покупателей из МойСклад (`entity/customerorder`). Карта: [Карта панели](/docs/panel-map/). API: `/api/ms-orders` → `routes/msOrders.js` — [REST API → Заказы в МС](/docs/api/#заказы-в-мс).

## Доступ

Ключ матрицы — **`ms-orders`**.

| Режим | Что доступно |
|-------|----------------|
| **`hidden`** | HTML и `/api/ms-orders` недоступны |
| **`view`** | list / filters / positions / freshness / status — GET |
| **`full`** | sync / sync-cancel |

В меню — после «Мой Склад (товары)», перед «Продажи МС».

## Настройки периода и исключений

Карточка **«Заказы в МС»** на [Настройках](/docs/settings/):

| Ключ | Смысл |
|------|--------|
| `ms_orders_sync_days` | Окно синка и списка (1…365, default **30**) |
| `ms_orders_exclude_owner_names` | Ответственные (подстрока, без регистра); default часто `Новикова И.` — не синкаются и не видны в списке |

Автосинк `task: 'ms_orders'` (default **08:00** МСК) — та же карточка + журнал на [Активность / Логи](/docs/processes/).

## UI

Эталон [moysklad baseline](/docs/moysklad/#эталон-списочной-страницы): «Фильтры и действия» + таблица.

1. Блок **актуальности** (`GET /data-freshness`): заказы + каталог/остатки МС (`ok` / `stale` / `running`).
2. Фильтры: умный поиск (номер / контрагент / товар в позициях), период ≤ sync_days, склад / контрагент / проект (мульти), оплата / отгрузка / остаток на складе заказа, проведённые, удалённые → только **«Применить»** / Enter.
3. При **поиске** или номере заказа фильтры `pay` / `ship` / `stock` **смягчаются** (`search_relaxed_filters`), чтобы предустановленное «Оплачено» не прятало найденный документ.
4. По умолчанию в UI часто только **оплаченные**; отгрузка и остаток — все.
5. Развернуть заказ → позиции (`GET /:uuid/positions`): qty, shipped, stock на складе заказа.
6. **Синхронизировать** / **Остановить** — фоновый job (лёгкий list, затем детали без исключённых owners).

Остатки по складу заказа — из `ms_export_stock_by_store` (полный синк [МойСклад](/docs/moysklad/)).

## Связь

- Не путать с [Продажами МС](/docs/ms-sales/) (`entity/demand`).
- Настройки периода — не в карточке фильтров заказов, а на `/settings.html`.
