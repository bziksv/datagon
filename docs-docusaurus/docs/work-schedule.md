# График работы

Модуль учёта рабочего времени, отпусков и начислений. Префикс таблиц `ws_*`, API `/api/work-schedule`.

## Доступ

| Роль | Как определяется | Что можно |
|------|------------------|-----------|
| Сотрудник | есть `ws_employee.user_id` = текущий user | clock start/stop, «Мой день», свои отпуска |
| Руководитель | `ws_department.head_user_id` = actor.id | матрица отдела, stuck, согласование отпусков отдела |
| Бухгалтерия | specialty «Бухгалтерия» или admin / «Полный доступ» | настройки, табель всех, payroll, audit, экспорт 1С, импорт CSV |

Страницы: `/work-schedule.html`, `/work-schedule-settings.html` (матрица `PAGE_DEFS`).

## Экраны

- **Мой день** — календарь, live-начисления, заявка на отпуск, зеркало кнопки Старт/Стоп из шапки.
- **Отдел** — матрица сотрудников×дни, сегодня, зависшие смены, очередь согласования.
- **Табель** — фильтры орг/отдел/месяц, KPI, правка ячеек, dry-run/apply payroll, экспорт CSV, журнал.

Кнопка часов в шапке (`DatagonWorkClock`) ходит в `POST /clock/start|stop`, `GET /clock/status`.

## Организации, отделы и стаж

На `/work-schedule-settings.html` — несколько юрлиц (селект + «Добавить» / «Удалить»). Seed при пустой таблице: **АЛЬМАМЕД** и **ВИЛМЕД** (без повторного создания после удаления).

**Отделы — общий справочник**, не привязаны к юрлицу: один отдел (например «Склад») можно выбрать сотруднику в любой организации. Импорт из **специальностей** Настроек (`specialties`, без «Полный доступ») — кнопка **«Подтянуть группы»**; имена уникальны глобально.

Сотрудник привязывается 1:1 к `users`, к **организации** и к **отделу** (любая комбинация). Поле **`hire_date`** обязательно для расчёта стажа (база + шаг организации после периода).

## Начисления (упрощённо)

Оклад = `salary × (сумма ставок дней / норма дней месяца)`. Стаж — от `hire_date` по формуле организации (база + шаг после 12 мес / `seniority_period_months`).

**Премия** (`premium_rule_json` у отдела, опционально `personal_premium_rule_json` у сотрудника):
- `stub` / пусто — нет премии;
- `fixed` + `amount` — фикс ₽ за месяц (сейчас единственное рабочее правило).
Приоритет: личное правило сотрудника → правило отдела. В payroll поле `premium`.
