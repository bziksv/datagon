**`/catalog-review.html`** (меню **Парсинг → Проверка каталога**, сразу после сопоставления). API: `/api/catalog-review`.

Две вкладки: **Товары на вывод** и **Товары на ввод**. Ввод пока без источника, очередь пустая.

## Товары на вывод

Кнопка **«Взять из архива»** берёт товары Альмамеда из архива сопоставления по родительским категориям, включая уже выключенные на Альмамеде. В колонке «Товар» название — ссылка на карточку на сайте. У выключенных подпись «Выключен на Альмамеде»: на других сайтах этой отметки может не быть. Фильтр **«На Альмамеде»** показывает всех, только включённых или только выключенных. Уже стоящие в очереди пропускаются. Архив сопоставления не очищается.

Категория сразу закрепляется за менеджером по продажам и контент-менеджером. Пока у категории не закреплены оба человека, статус **Не распределено**. После закрепления обоих новые строки сразу **У менеджера**. Над таблицей закрепления — сводка, у кого сколько категорий и карточек архива. Полоска пересчитывается сразу при смене человека в строке, ещё до «Сохранить закрепление».

Решение ставится списком в колонке «Решение» и сразу пишет на Альмамед. «Снят / аналог» и «Не поставляется» включают галку характеристики. «Деактивировать» выключает карточку. Отдельных кнопок «На сайт» и «Вернуть» нет. Если при выключении остаток больше нуля, нужно подтверждение. Колонки «Контент» и «Статус» в очереди пока скрыты. Вместо фильтра «Статус» стоит фильтр «Решение»: можно отметить несколько значений, в том числе «Не выбрано». Есть фильтр **«Менеджер»** (несколько менеджеров по продажам + «Без менеджера», с поиском). После **«Применить»** фильтры пишутся в URL (можно скопировать ссылку). Выбор также запоминается локально.

Решение в колонке доступно **менеджеру по продажам этой строки** и специальности **«Руководитель контент отдела»** (любые строки). Admin / «Полный доступ» — тоже.

Решение менеджера:

| Решение | Дальше |
|---|---|
| Оставить включенным (`keep`) | карточку **включают** на Альмамеде (`source_enabled=1`). Если стояли галки «Снят / аналог» / «Не поставляется» отсюда — снимаются |
| Оставить тек. состояние (`keep_as_is`) | сайт **не трогаем** (остаётся как есть — включён или выключен). Галки отсюда при смене снимаются |
| Снят / аналог | нужен комментарий, куда поставить аналог или что взять в работу. Галка на Альмамеде включается сразу |
| Не поставляется | галка «Не поставляется» включается сразу |
| Деактивировать | карточка выключается на Альмамеде |

Если при деактивации остаток на складах сайта больше нуля, нужно отдельное подтверждение. «Не выбрано» снимает решение, убирает галки «Снят / аналог» и «Не поставляется», если они были поставлены отсюда, и снова включает карточку, если её выключили решением «Деактивировать». Уже выключенные до проверки каталога «Оставить тек. состояние» не включает — для включения берите «Оставить включенным».

На ячейках решения и менеджера при наведении есть кнопка **лог** — журнал только этого поля. У товара кнопка **лог** показывает всю строку: кто, когда и что было → стало. Доступ к странице — ключ `catalog-review` в матрице специальностей (для новых групп по умолчанию `hidden`, у «Полный доступ» — `full`).
