**`/catalog-review.html`** (меню **Парсинг → Проверка каталога**, сразу после сопоставления). API: `/api/catalog-review`.

Две вкладки: **Товары на вывод** и **Товары на ввод**. Ввод пока без источника, очередь пустая.

## Товары на вывод

Кнопка **«Взять из архива»** берёт товары Альмамеда из `match_manual_archive` по отмеченным родительским категориям Webasyst. Одна строка на карточку. Уже стоящие в очереди и выключенные на сайте (`source_enabled = 0`) пропускаются. Архив сопоставления не очищается.

Закрепление менеджера и контента — отдельная вкладка **«Закрепление категорий»**. В очереди этих людей меняют прямо в колонках «Менеджер» и «Контент». Пока у категории не закреплены оба человека, статус **Не распределено**. После закрепления обоих новые строки сразу **У менеджера**.

Под кнопками решений — журнал: что сделали, фильтры, сколько записано и пропущено, комментарий, время и ошибки.

Решение менеджера:

| Решение | Дальше |
|---|---|
| Оставить | сразу **Готово**, сайт не трогаем |
| Снят / аналог | нужен комментарий, куда поставить аналог или что взять в работу; дальше **У контента**, галка пишется по «Сделано на сайте». Комментарий в колонке «Решение» можно поправить, пока строка не закрыта |
| Не поставляется | то же |
| Деактивировать | то же, карточка выключается в CMS |

Если при деактивации остаток на складах сайта больше нуля, нужно отдельное подтверждение. Контент может вернуть строку менеджеру с комментарием.

Фильтр «Мои» для не-admin по умолчанию. Доступ к странице — ключ `catalog-review` в матрице специальностей (для новых групп по умолчанию `hidden`, у «Полный доступ» — `full`).
