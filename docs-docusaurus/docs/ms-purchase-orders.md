# Заказы поставщикам

Страница **`/ms-purchase-orders.html`** — заказы поставщикам МойСклад (`entity/purchaseorder`).

Не путать с [«Заказы в МС»](/docs/ms-orders) (`customerorder` — покупатели).

## Данные

- Синк шапок в таблицу **`ms_purchase_order`** (сумма, оплачено, принято = `shippedSum`, склад, статус).
- **Приёмки** (`entity/supply`) не синкаются.
- Автосинк: задача `ms_purchase_orders` в настройках; «Запустить сейчас» или кнопка на странице.

## KPI / пресеты

| Пресет | Смысл | Сумма |
|--------|--------|-------|
| **A** | Оплачено, ещё ничего не принято | Σ суммы заказа |
| **B** | Оплачено, частично принято; статусы «Без статуса» / «Ждём доставку» / «Есть проблема» | Σ (сумма − принято) |

Те же цифры на [`/finance.html`](/docs/finance) как отдельные KPI (**не** входят в «Товар (МС)» / «С товаром»).

API: `/api/ms-purchase-orders/*` — см. [REST API](/docs/api).
