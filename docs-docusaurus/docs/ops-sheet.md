Страница **`/ops-sheet.html`** — операционный лист за выбранный год: по каждому месяцу все менеджеры продаж и строка **ИТОГО**. Источник колонок — вкладка года Google-книги «Операционный лист» (блок продаж, колонки до **План**). Блоки логистики / складов / маркетов / Прайм **пока не перенесены**.

## Доступ

Ключ матрицы специальностей — **`ops-sheet`**.

- **`hidden`** — страница и `/api/ops-sheet` недоступны.
- **`view`** — полный свод по всем менеджерам, только просмотр.
- **`full`** — полный свод + правка ручных ячеек (коэффициент, оклад, премия с прошлыми месяцами) + синк Planfix и привязка статусов.

В отличие от [Таблиц менеджеров](/docs/manager-sales), здесь **нет** ограничения «только своя таблица»: любой с доступом к странице видит всех менеджеров специальности **Менеджер по продажам**.

## Как пользоваться

1. Выберите **год** и **период Planfix**, при необходимости введите ФИО в поиске, нажмите **Применить** (или Enter в поиске). После применения фильтры пишутся в адрес: `year`, `month` (номер месяца или `all` = весь год), `search`, при открытых задачах Planfix — `q` и `page`. **Перейти к месяцу** добавляет `jump=10` (только прокрутка). Ссылку можно скопировать коллеге — откроется та же выборка.
2. **Перейти к месяцу** — только прокрутка к блоку «Январь»…«Декабрь» в листе ниже (не фильтр и не синк Planfix).
3. Жёлтые ячейки — **ручной ввод** (коэффициент, оклад, премия с прошлыми месяцами): клик → правка → Enter / blur сохраняет; Esc отменяет.
4. **Кол-во заявок** считается из Planfix: менеджер в задаче — **постановщик**, месяц — **дата создания**. Значения поля **«Статус Сделки/Письма»** привязываются к корзинам на этой же странице (в работе / оплаченная / отказная / инфо/спам / Поставщик / отказ без товара или документации / Агрегатор). Список статусов — в том же порядке, что в Planfix, с разделителями `-----`; строки можно переставлять перетаскиванием за ⋮⋮. В колонку попадают только статусы с галкой «в кол-во заявок» (по умолчанию все, кроме инфо/спам).
5. **Оплаченные заявки** — число строк продаж за месяц, не статус Planfix.
6. **Период Planfix** (рядом с годом): месяц или «Весь год». **Синхронизировать Planfix** забирает задачи за период и отдельно выгружает справочник **«Статус Сделки/Письма»** (Отправлено КП, Обработка запроса, отказ…) — эти значения привязываются к корзинам. Системный статус задачи (Новая / В работе / Завершенная) пишется в колонку **Статус Планфикс** и в корзины не идёт. Номер открывается как `https://{аккаунт}.planfix.ru/task/{id}`. Токен — **Настройки → Planfix**.
7. **🧩 Столбцы** / **📏 Ширины** — видимость и ширины колонок (сохраняются в браузере).

Поиск менеджера применяется **только** по «Применить» / Enter (или Esc / «×» — очистка и сразу применить). ИТОГО при активном поиске пересчитывается по видимым строкам.

## Колонки

| Колонка | Тип | Смысл |
|--------|-----|--------|
| Оборот | auto | Сумма «без доставки» credit-менеджера за месяц |
| Прибыль до / после налога | auto | До — без 16%; после — `SUM(diff)` |
| Общий % прибыли | derived | Прибыль после налога / оборот × 100 |
| Премия за текущий месяц | auto | Как в таблицах менеджеров: от % МП. и плана |
| Кол-во заявок | auto | Задачи Planfix постановщика за месяц создания; статусы с галкой «в кол-во заявок» |
| Коэффициент | manual | Ввод вручную |
| Оплаченные заявки | auto | Число продаж за месяц: один № нашего счёта — одна продажа (две строки НДС не считаются дважды) |
| Отношение продаж к заявкам | derived | Заявки / оплаченные |
| Средний чек | derived | Оборот / оплаченные |
| Премия с прошлыми месяцами, оклад | manual | Ввод вручную |
| Фактическая прибыль | derived | Прибыль после налога − премия месяца − оклад |
| Зарплата с премиями прошлых | derived | Оклад + премия с прошлыми |
| Прибыль фирмы | derived | Прибыль после налога − зарплата с премиями |
| % от оборота с вычетом зарплат | derived | Прибыль фирмы / оборот × 100 |
| План | auto | «выполнен» / «не выполнен» относительно плана менеджера |
