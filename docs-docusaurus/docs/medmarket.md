# Медмаркет

Страница **`/medmarket.html`** — стыковка позиций МойСклад с кодом товара для **Медмаркета**.

Ключ строки: **код МС** + **тип** (`товар` | `комплект` | `услуга`). Тип выводится из поля `type` в `ms_export` (см. `lib/datagonMedmarketType.js`).

## Колонки

| Колонка | Источник |
|--------|----------|
| Код | `ms_export.code` |
| Наименование | `ms_export.name` |
| Тип | нормализованный тип МС |
| Код товара для медмаркета | связка **`код МС+Тип`** (как в Motion), напр. `10088+Товар` — те же код и тип, что в карточке товара; хранится в `dg_medmarket_map.medmarket_code` |

## Действия

- **Применить** — фильтры по коду, наименованию, типу, коду Медмаркета, признаку «есть/нет стыковки».
- **Обновить каталог из МС** — код, наименование, тип из `ms_export` (коды стыковки не затираются).
- **Заполнить коды Медмаркета** — для строк по текущим фильтрам: если поле пустое или не совпадает с `код+Тип`, записывается каноническое значение (`POST /api/medmarket/fill-linkage-codes`). Уже верные строки не трогаются.
- **Запустить синхронизацию сейчас** (в настройках) — та же задача `medmarket` по расписанию. Журнал — `/processes.html`.
- Редактирование в таблице — `PATCH /api/medmarket/mapping` при изменении ячейки.

## Автосинхронизация

На **`/settings.html`** (блок «Медмаркет: каталог из МС»): включение, время (МСК), дни недели (по умолчанию пн и чт), «Запустить сейчас».

Журнал запусков — **`/processes.html`**, раздел «Автосинхронизация по расписанию», задача **`medmarket`**.

Ключи `app_settings`: `auto_sync_medmarket_enabled`, `auto_sync_medmarket_time`, `auto_sync_medmarket_weekdays`.

Подробнее — [API](api.md) (`/api/medmarket`, `POST /api/settings/auto-sync-run`).
