# Медмаркет

Страница **`/medmarket.html`** — стыковка позиций МойСклад с кодом товара для **Медмаркета**.

Ключ строки: **код МС** + **тип** (`товар` | `комплект` | `услуга`). Тип выводится из поля `type` в `ms_export` (см. `lib/datagonMedmarketType.js`).

## Колонки

| Колонка | Источник |
|--------|----------|
| Код | `ms_export.code` |
| Наименование | `ms_export.name` |
| Тип | нормализованный тип МС |
| Код товара для медмаркета | связка **`код МС+Тип`** (как в Motion), напр. `10088+Товар`; хранится в `ms_export.medmarket_product_code`. Пустая ячейка + серая строка «ожидается: …» — **не** стыковка, только подсказка. |

## Действия

- **Применить** — фильтры по коду, наименованию, типу, коду Медмаркета, **Стыковка** (есть/нет валидной связки **код+тип** в колонке «Код товара для медмаркета», не просто непустое поле).
- **Подтянуть из карточек МС** — значение атрибута из `ms_entity_details.payload_json` → `ms_export.medmarket_product_code` (без повторной записи уже заполненных строк; извлечение атрибута в SQL, чанк 6000).
- **Заполнить коды в МойСклад** — для строк по **применённым** фильтрам: в атрибут МС и `ms_export` пишется каноническое `код+Тип` (`POST /api/medmarket/fill-linkage-codes`). Сначала на странице показывается **пробный отчёт** (`dry_run=1`), затем запись. Inline-журнал `#mm-action-log` — фильтры, счётчики, ошибки МС (см. `datagon-action-log-extended.mdc`).
- **Запустить синхронизацию сейчас** (в настройках) — та же задача `medmarket` по расписанию. Журнал — `/processes.html`.
- Редактирование в таблице — `PATCH /api/medmarket/mapping` при изменении ячейки.

## Автосинхронизация

На **`/settings.html`**, блок **«Экспорт в МС»** (обе задачи Медмаркет):

| Задача | Что делает | Рекомендуемые дни (МСК) |
|--------|------------|-------------------------|
| **`medmarket`** — полная выгрузка в `ms_export` | Импорт атрибута из `ms_entity_details` → `ms_export` (~58&nbsp;000 позиций), **без записи в МС**. | **только вс**, 09:00 |
| **`medmarket_fill`** — код+тип в МойСклад | Как **«Заполнить коды в МойСклад»**: очередь **~10–12&nbsp;тыс.** исправлений формата/регистра; ~46&nbsp;тыс. уже со стыковкой пропускаются. | **пн–сб**, 09:30 |

Журнал — **`/processes.html`**, `task_type` **`medmarket`** или **`medmarket_fill`**.

Ключи: `auto_sync_medmarket_*`, `auto_sync_medmarket_fill_enabled`, `auto_sync_medmarket_fill_time`, `auto_sync_medmarket_fill_weekdays`.

Подробнее — [API](api.md) (`/api/medmarket`, `POST /api/settings/auto-sync-run`).
