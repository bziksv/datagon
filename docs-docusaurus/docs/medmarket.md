Страница **`/medmarket.html`** — стыковка позиций МойСклад с кодом товара для **Медмаркета**. Карта: [Карта панели](/docs/panel-map/). API: `/api/medmarket` → `routes/medmarket.js`.

Ключ строки: **код МС** + **тип** (`товар` | `комплект` | `услуга`). Тип из `ms_export.type` (`lib/datagonMedmarketType.js`). Каноническая связка: **`код+Тип`** (как в Motion), напр. `10088+Товар` → поле `ms_export.medmarket_product_code`.

## Доступ

Ключ матрицы — **`medmarket`**.

| Режим | Что доступно |
|-------|----------------|
| **`hidden`** | HTML и `/api/medmarket` недоступны |
| **`view`** | Список / sync-status — GET |
| **`full`** | sync, PATCH mapping, import, fill-linkage-codes |

## Колонки

| Колонка | Источник |
|--------|----------|
| Код | `ms_export.code` |
| Наименование | `ms_export.name` |
| Тип | нормализованный тип МС |
| Код товара для медмаркета | связка **`код+Тип`**. Пустая ячейка + серая подсказка «ожидается: …» — **не** стыковка |

## Действия

- **Применить** — фильтры (код, имя, тип, код Медмаркета, **Стыковка** = есть валидная связка код+тип, не просто непустое поле). Только по кнопке / Enter.
- **Подтянуть из карточек МС** — атрибут из `ms_entity_details.payload_json` → `ms_export` (`POST /sync` / import; без перезаписи уже заполненных; чанк ~6000).
- **Заполнить коды в МойСклад** — по **применённым** фильтрам пишет канон в атрибут МС и БД (`POST /fill-linkage-codes`). Сначала **dry_run**, затем запись. Журнал `#mm-action-log`: фильтры, счётчики, ошибки МС (не одна строка «идёт…»).
- Правка ячейки → `PATCH /mapping`.

## Автосинхронизация

На [Настройках](/docs/settings/), блок **«Экспорт в МС»**:

| Задача | Что делает | Рекомендуемые дни (МСК) |
|--------|------------|-------------------------|
| **`medmarket`** | Импорт атрибута → `ms_export` (**без** записи в МС) | **только вс**, 09:00 |
| **`medmarket_fill`** | Как «Заполнить коды…» без фильтров (~10–12 тыс. правок, остальные skip) | **пн–сб**, 09:30 |

Журнал — [Активность / Логи](/docs/processes/), `task_type` `medmarket` / `medmarket_fill`.

## Связь

Зависит от актуального [МойСклад](/docs/moysklad/) (`ms_export` + `ms_entity_details`). Не путать с синком каталога `moysklad`.
