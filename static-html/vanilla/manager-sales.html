В архив?

Строка не удаляется. Она попадёт в архив этой таблицы (кнопка «Архив»). Оттуда её можно вернуть.

Добавить строку

Свод «Все менеджеры» только для просмотра. Выберите, в чью таблицу писать.

Передать заказ

Эта же строка появится в таблице выбранного менеджера в том же месяце (по дате оплаты). У каждого может остаться своя копия заказа с тем же номером счёта. У вас суммы, % МП. и премия по этой переданной строке показываются нулями и не входят в план. У него они прибавляются, если в строке есть сумма.

Счёт поставщика

Вставьте ссылку на счёт или выберите «Склад», если товара со склада.

Подсветка счёта поставщика

Выберите цвет для ссылки на счёт поставщика.

Отметка нашего счёта

Помечаем зелёным, если создан заказ покупателя + счёт + входящий платёж.

Комментарий

Новый комментарий появится сверху. Редактировать сможете только свой.

Удалить комментарий?

Комментарий будет удалён без возможности восстановить.

Отправка вместе

Укажите № нашего счёта другой строки — они поедут одной отправкой.

Планы продаж по годам и менеджерам

У каждого года свой план и свои пороги % МП.: сначала общий план года, затем персональный у менеджера, затем месяц (отпуск). % МП. считается от суммы «без доставки» за месяц. Пустая ячейка плана наследует значение слева. Менять планы и пороги могут только Полный доступ и Бухгалтерия.

Режим просмотра: поля плана и порогов % МП. недоступны для изменения.
