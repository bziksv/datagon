Маркетплейсы — Настройки
Меню Маркетплейсы → Настройки: ключи API и справка. Таблицы выгрузок — на отдельных страницах Ozon, Wildberries, Яндекс Маркет (пункты того же подменю).
Как устроено
  • Ключи. Сначала переменные окружения сервера: OZON_CLIENT_ID, OZON_API_KEY, WB_API_KEY, YM_API_KEY, YM_CAMPAIGN_ID, при необходимости YM_BUSINESS_ID. Иначе — значения из БД (app_settings), форма ниже (админ или полный доступ к «Настройкам» приложения).
  • Таблицы. На страницах Ozon / Wildberries / Яндекс Маркет сервер отдаёт выборку в wide-таблицу (до 40 строк) и CSV по кнопкам на этих страницах.
  • Лимиты API. См. GET /api/exports/marketplaces/status (rate_limits_ms_min); паузы в query только увеличиваются; при 429/503 — повтор с backoff.
