Lagerplus — Закупки (v0)
Закупочный модуль для товаров МойСклад. Адаптация фич из neeil1990/store (suppliers / out-of-stock / shipper) под Datagon. v0 — read-only список с фильтрами «дефицит / нулевые» и неснижаемым остатком МС.
Фильтры и действия

Эффективный норматив = min_stock_lager (override Lager поверх МС-значения), иначе ms_export.min_stock (нативное product.minimumBalance из МС). Колонка «Норматив (Lager)» — редактируемая (Tab/Enter — сохранить, Esc — отменить). Кнопка «↗» в строке отправляет норматив этой позиции в МС, балк-кнопки в шапке — отправляют все правки сразу. Для Комплектов отправка в МС не выполняется (в МС-схеме bundle поле minimumBalance не задано).
