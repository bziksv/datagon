Медмаркет
Код, наименование и тип подтягиваются из МойСклад по расписанию (Настройки → Автосинхронизация). Данные только из атрибута МойСклад «Код товара для медмаркета» (как на Мой Склад). Отдельной таблицы нет — колонка в ms_export после синка МС.
Фильтры и действия
По сохранённому значению в БД; серая подсказка в таблице — не стыковка.

После полного синка Мой Склад значения атрибута уже в ms_export — обычно этого достаточно. «Подтянуть из карточек МС» — догонка только по карточкам, где атрибут есть в сохранённом JSON (не весь каталог ~50k+), обычно несколько минут. Редактирование в таблице пишет в тот же атрибут в МойСклад.
