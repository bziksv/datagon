Кнопки «Запустить сейчас» отправляют задачу на сервер (очередь + один воркер). Результат последнего нажатия — в плашке ниже; ход выполнения — на странице «Логи фоновых процессов». Кнопка «Лог» на карточке открывает журнал запусков этой задачи за выбранный день (МСК) из таблицы auto_sync_runs.

Задачи сгруппированы по типу (сначала импорт из МойСклад, затем экспорт в МС и остальные), внутри группы — по времени (МСК). Порядок и предупреждения о совпадении обновляются после выбора времени (когда поле теряет фокус или закрывается выбор в часах). Выгрузки в МойСклад — в блоке «Экспорт в МС».
