Маркетплейсы — Проблемы с товарами
Товары МойСклад (фильтр «Складская позиция = Да» и «Перестали сотрудничать = Нет») с сопоставлением артикулов на Ozon, Wildberries и Я.Маркете. Если кода маркетплейса нет в последнем снапшоте — ячейки «Код» и «Название» подсвечены красным.
Гайд Как пользоваться страницей «Проблемы с товарами»

Список строится по товарам МойСклад (складская позиция, не «перестали сотрудничать») и по последним сохранённым снапшотам Ozon, Wildberries и Я.Маркета. Сначала убедитесь, что снапшоты актуальны, затем настройте фильтр и примените его; в таблице смотрите красные ячейки и при необходимости сузьте поиск.

Что хранится в браузере
  1. Состояние гайда — развёрнутость панели и блоков шагов 1–3, ключи datagon_mp_issues_workflow_* в localStorage. На данные в МойСклад и снапшоты не влияет.
  2. Фильтры и видимость полей — селекты менеджеров, scope, чекбокс «Исключить товары из комплектов» (dg.mpu.flt.excludeBundleComponents.v1, дефолт включён), ползунок «Умное скрытие столбцов под выбранный фильтр» (dg.mpu.flt.smartColumns.v1, дефолт включён), настройки шестерёнки «Поля фильтров» (datagon_mpu_filter_fields_v1).
  3. Таблица — какие колонки показаны и ширины в пикселях (dg.mpu.colvisible.v5, dg.mpu.colwidths.v2). По умолчанию включены все колонки — «Код МС», «Название МС», «Менеджер», «Контент-менеджер», «НДС МС», «Остаток по МС», габариты МС (Длина, Ширина, Высота — коробка, Высота — пакет (см), Вес (кг) — из ms_dimensions_measurements, страница Габариты), «Синхронизация МС» и полный паспорт каждого маркетплейса (код, название, НДС, остаток, длина / ширина / высота / вес, кабинет, покупателю, обновлено). Кнопка «Столбцы по умолчанию» возвращает именно это состояние «все включены». Лишние колонки можно скрыть через 🧩 Столбцы. Полное наименование МС и ссылки на маркетплейсы — по клику на «Название МС» (карточка МойСклад).
Шаг 1
Актуальные снапшоты маркетплейсов

Откройте разделы Маркетплейсы → Ozon, Wildberries, Яндекс Маркет и при необходимости нажмите «Обновить из маркетплейса» или загрузите последнее сохранённое. Эта страница сравнивает коды МС с тем, что есть в последнем снапшоте каждого кабинета; без обновления список «проблем» может быть устаревшим.

Ключи API задаются в Настройках маркетплейсов.

Шаг 2
Фильтры и действия

Выберите фильтр маркетплейса (все товары / есть проблемы хотя бы на одном / нет ни на одном / нет на конкретном маркетплейсе / не совпадает НДС / разные габариты — со сверкой с МС, когда есть замеры в реестре Габариты, иначе между маркетплейсами). При необходимости сузьте выбор селектами Менеджер и Контент-менеджер.

Чекбокс «Исключить товары, по которым есть комплекты» (включён по умолчанию) скрывает товары, чей code встречается в составе хотя бы одного комплекта (берётся из ms_entity_details, kind=bundle, поле payload_json.components.rows[].assortment.code). Это исключает «ложные проблемы» по штучным товарам, которые отгружаются комплектом и не выкладываются на маркетплейс отдельно. Снимите галку, если хотите видеть полный список.

Ползунок «Умное скрытие столбцов под выбранный фильтр» (включён по умолчанию) при Применить на фильтрах Нет на Ozon / Нет на Wildberries / Нет на Я.Маркет / Не совпадает НДС / Разные габариты оставляет в таблице только базовые колонки МойСклад (Код, Название, Менеджер, Контент-менеджер, НДС, Остаток, Синхронизация) и колонки, относящиеся к проблеме: на «нет на <маркетплейс>» — пара Код / Название этой площадки; на «не совпадает НДС» — все три НДС маркетплейсов; на «разные габариты» — длина / ширина / высота / вес по всем трём площадкам. На фильтрах Все товары, Есть проблемы, Нет ни на одном ползунок ничего не меняет — отображаются столбцы по выбору в 🧩 Столбцы. Выключите ползунок, чтобы вернуть полный набор и выбирать видимость вручную.

Пока вы меняете поля, это черновик: таблица и счётчики обновятся только после Применить или Enter в поле умного поиска в шапке таблицы. Кнопка По умолчанию сбрасывает scope, менеджеров и поиск к начальному состоянию и снова включает «исключить товары из комплектов» и «умное скрытие столбцов», после чего сразу применяет. Бейдж «не применено» напоминает, что на экране ещё старый набор фильтров.

Шаг 3
Таблица и подсветка

Умный поиск в шапке карточки таблицы ищет по артикулам и наименованиям МС и маркетплейсов, а также по ФИО менеджеров (мульти-слова через пробел — как AND). Esc или крестик в поле очищают строку и сразу применяют фильтр.

При фильтре «Все товары» красным подсвечиваются только ячейки кода маркетплейса (Ozon / Wildberries / Я.Маркет), если товар в снапшоте не найден. Несовпадение НДС (МС ↔ площадка) и расхождение габаритов подсвечиваются на соответствующих фильтрах, не в режиме «все товары». На остальных фильтрах при отсутствии товара подсвечивается пара код + название для этой площадки. На фильтре «Не совпадает НДС» ячейки НДС маркетплейсов с расхождением подсвечиваются красным, а НДС МС — мягким жёлтым: это справочное значение со стороны МС, фактическая ошибка — на маркетплейсе.

На фильтре «Разные габариты», если у товара заполнены замеры МС в реестре Габариты (хотя бы одно значение из «Длина», «Ширина», «Высота — коробка», «Высота — пакет», «Вес»), сверка идёт МС ↔ маркетплейсы: ячейка маркетплейса и соответствующая ячейка МС подсвечиваются, когда числа расходятся (допуск 0,02). Высота МС двойная (коробка / пакет): высота маркетплейса считается совпавшей, если совпала хотя бы с одной из непустых высот МС. Если у строки в МС нет ни одного измерения — fallback «между маркетплейсами»: для каждой оси (длина / ширина / высота / вес) собираются значения всех маркетплейсов, у которых есть карточка по товару, и подсвечиваются отклонения от большинства. Например, при 50 / 20 / 50 по ширине красным становится только колонка с «20» — две другие совпадают и принимаются за эталон. Если уникального большинства нет (три разных значения, либо ровно две площадки и значения разные) — подсвечиваются все, у кого значение определено; пустые ячейки расхождением не считаются.

Подсветка по слоту габарита при наведении. Когда вы наводите мышь на любую ячейку длины / ширины / высоты / веса (МС или маркетплейс), все ячейки этого же слота в текущей строке получают синюю обводку — так не нужно «бегать глазами» по таблице, чтобы сравнить, например, ширину Ozon с шириной Wildberries и Я.Маркет. У МС высота двойная (коробка и пакет): обе подсвечиваются вместе с маркетплейсной высотой.

Кнопки 🧩 Столбцы и 📏 Ширины в шапке таблицы открывают панели ниже. По умолчанию (и при клике на «Столбцы по умолчанию») включены ВСЕ колонки: по МС — Менеджер, Контент-менеджер, НДС, Остаток, Синхронизация, по каждому маркетплейсу — Код, Название, НДС, Остаток, Длина/Ширина/Высота (см), Вес (кг), Кабинет (ссылка на товар), Покупателю (ссылка на товар), Обновлено. Широкая таблица — как на странице «Мои товары»: горизонтальный скролл внутри карточки, шапка «плывёт» под верхним меню. Сузить можно через 🧩 Столбцы и 📏 Ширины (сохраняется в браузере). Полное наименование МС и переход в МойСклад — по клику на «Название МС». Пагинация: стартовый размер страницы 100 строк.

Журнал снимков «есть проблемы»

Обновить список — только перечитать журнал с сервера (новых строк сам по себе не появится). Записать снимок сейчас — добавить строку в журнал по текущим данным в БД (тот же смысл, что фильтр «Есть проблемы» и «исключить комплекты»), без запросов к API маркетплейсов. После каждого успешного полного обновления маркетплейсов (кнопка «Обновить из маркетплейсов» в настройках или автосинк по расписанию) снимок тоже записывается автоматически.

Динамика по сотрудникам

Столбцы — снимки слева направо по времени (сначала более старые). Насыщенность фона — доля проблем у сотрудника в этом снимке относительно других в тот же день; под числом — изменение к предыдущему снимку (▲ рост, ▼ снижение).
