Статусы Planfix «Статус Сделки/Письма»

Синхронизировать Planfix — заявки + отчёт. Только отчёт — generate 450694 и статусы, без повторной выгрузки задач (если период в UI Planfix ≠ периоду Datagon — синк стоп, гистограмма не затирается). Пока идёт синк — Остановить. В отчёте Planfix — снимок по выбранному году/месяцу (короткий синк не убивает полный год). Даты generate — как в UI Planfix. Токен — Настройки → Planfix.
