Статусы Planfix «Статус Сделки/Письма»

Синхронизировать Planfix — заявки + отчёт. Только отчёт — generate 450694 и статусы, без повторной выгрузки задач (если период в UI Planfix ≠ периоду Datagon — синк стоп, гистограмма не затирается). Пока идёт синк — Остановить. В отчёте Planfix — снимок месяца. Он перезаписывается только если в Planfix выставлен этот же месяц (сейв почти целиком про него). «Последние 14/90 дней» обновляют статусы заявок и не затирают уже снятые месяцы. Даты generate — как в UI Planfix. Токен — Настройки → Planfix.
