Huckster
Таблицы Huckster Export и Huckster Export RRC строятся от товаров МойСклад: код МС сопоставляется с UID в Huckster по кабинетам Ozon, WB и ЯМ. В блоке Наборы задаются кабинеты для каждого набора и опциональный Тип цены МойСклад. Если тип цены выбран, при обновлении остаются только товары, где эта цена больше 0, а в таблицу добавляется колонка с названием цены и её значением. Репрайсер ВКЛЮЧЕН означает, что по UID найден ровно один включённый repricer для маркетплейса; Репрайсер ВЫКЛЮЧЕН — товар не найден, выключен или кабинет не определяется однозначно. Колонки Модель показывают назначение Unit-модели; при ненулевой Автоматизация цены в МС число% в названии модели должно совпадать с выгрузкой (фильтр «Модели»). Актуально на — время сборки снимка Datagon. См. wiki Huckster.
Наборы
Набор 1 (Huckster Export)
Если выбран тип цены, в таблицу попадут только товары, где эта цена больше 0.
Набор 2 (Huckster Export RRC)
Для RRC можно выбрать цену РРЦ, чтобы убрать строки с нулевой ценой из МойСклад.

Наборы сохраняются кнопкой выше; тот же конфиг доступен и через GET/POST /api/exports/huckster/config.
