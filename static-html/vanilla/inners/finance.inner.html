Настройки банка

В кабинете Точки: Интеграции и API → скопируйте JWT (длинный токен) и вставьте сюда. Нужны scopes ReadAccounts, ReadBalances, ReadStatements.

Client ID и Client Secret на этой странице не вводятся — они для OAuth/приложений; Datagon в этом релизе работает только по JWT из кабинета. Redirect URL тоже не нужен.
