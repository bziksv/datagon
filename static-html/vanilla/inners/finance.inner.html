Финансы
Точка, Райффайзен и Т‑Банк: счета, остатки и движение (только чтение). Ключи — в карточке настроек при полном доступе. Расписание — Настройки · журнал — processes.
Настройки банка

Точка: несколько JWT — по одному на организацию (или один ключ с правами на все компании). При генерации отметьте ReadAccounts, ReadBalances, ReadStatements.

Райффайзен: в RBO «Интеграция банка с учетными системами» → API-оркестратор → refresh_token. В Datagon сохраняются client_id, client_secret и refresh_token.

Т‑Банк: кабинет Т‑Бизнес → «Интеграции» → T‑API → «Выпустить токен» (Bearer). В токене должен быть IP машины, с которой ходит Datagon.

Аналитика по месяцам Все организации
Нет проводок за выбранный период — загрузите выписки.

По снимку из БД. Организация и счёт — из применённых фильтров. По умолчанию без внутреннего оборота: тело депозита (UNV), «Перевод собственных средств» (расчётный ↔ фонд) и выплаты дивидендов. Капитал / займ учредителей (галка «займ» в таблице движения) никогда не входит в график: это не деньги фирмы. Галка «Не учитывать расход на ИНН 362903774541» (вкл. по умолчанию) убирает из графика и топа контрагентов исходящие платежи на этот ИНН — в «Движении» они остаются. Проценты и реальные платежи из фонда остаются. Зелёный — входящие, красный — исходящие, синяя линия — чистый поток (как в фильтре графика). Оранжевая линия — остаток на конец месяца (= расчётные + оценка депозитов, как «Всего доступно»; walkback по полной выписке); в подсказке — разница к предыдущему месяцу и разбивка. KPI «Разница» — изменение остатка за весь выбранный период. Клик по столбцу месяца подставляет «С даты» / «По дату» (и направление) — остаётся нажать «Применить».
