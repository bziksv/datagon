Финансы
Точка и Райффайзен: счета, остатки и движение (только чтение). Ключи — в карточке настроек при полном доступе. Расписание — Настройки · журнал — processes.
Настройки банка

Точка: несколько JWT — по одному на организацию (или один ключ с правами на все компании). При генерации отметьте ReadAccounts, ReadBalances, ReadStatements.

Райффайзен: в RBO «Интеграция банка с учетными системами» → API-оркестратор → refresh_token. В Datagon сохраняются client_id, client_secret и refresh_token (банк ротирует refresh при каждом обновлении).

Аналитика по месяцам Все организации
Нет проводок за выбранный период — загрузите выписки.

По снимку из БД. Организация и счёт — из применённых фильтров. По умолчанию без внутреннего оборота: тело депозита (UNV), «Перевод собственных средств» (расчётный ↔ фонд) и выплаты дивидендов. Проценты и реальные платежи из фонда остаются. Зелёный — входящие, красный — исходящие, линия — чистый поток. Клик по столбцу месяца подставляет «С даты» / «По дату» (и направление) — остаётся нажать «Применить».
