# Google Apps Script (вне репозитория Google)

Файл **`huckster-sheets-export.gs`** — выгрузка листов Huckster с логикой как у Datagon (`routes/exportsHuckster.js`).

**В этом файле нет `onOpen`.** Добавьте его **отдельным файлом** в проект, где уже есть ваше меню.

Если раньше был «простой» скрипт с теми же **`exportHucksterExport` / `runAllExports`** — его нужно **удалить из проекта целиком**, иначе будет **две функции с одним именем**, проект не скомпилируется и меню не появится. Подробно: **`INSTALL.md`**.

В репозитории файл для хранения и диффов; в Google он не выполняется сам по себе.

## Быстрый тест по UID

Для проверки без полной выгрузки есть отдельные функции:

- `runAllExportsTest12461()` — тестовый запуск по `hck_TEST_UIDS` (по умолчанию `["12461"]`), пишет в листы `Huckster Export TEST` и `Huckster Export RRC TEST`.
- `runAllExportsForUidList()` — спрашивает список UID через prompt (через запятую, пробел или новую строку) и пишет в те же тестовые листы.

В тестовом режиме в матрицу попадают только указанные UID; пагинация `repricer/items/list` по кабинету останавливается раньше, если все нужные UID уже найдены.
