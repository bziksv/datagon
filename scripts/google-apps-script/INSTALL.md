# Подключение `huckster-sheets-export.gs` без поломки меню

## Что на самом деле ломает меню

В Google Apps Script **все файлы `.gs` одного проекта делят один глобальный scope**. Если редактор показывает ошибку компиляции (часто в **Выполнение** — иконка «жук»), **ни один** триггер, включая `onOpen`, не отработает — пользовательское меню просто не создаётся.

Это **не** из‑за «лишней сложности» кода в репозитории, а из‑за типичных конфликтов:

| Проблема | Следствие |
|----------|-----------|
| Два `function onOpen()` в проекте | конфликт / ошибка |
| Дважды объявлены **`exportHucksterExport`**, **`exportHucksterExportRRC`** или **`runAllExports`** | ошибка: функция уже объявлена |
| В V8 дважды **`const SHOPS_SET_1`** (или то же имя в двух файлах) | ошибка: идентификатор уже объявлен |

Префикс **`hck_`** у внутренних имён как раз для того, чтобы **не пересекаться** с вашим старым **`runExport`**, **`fetchAllProducts`**, **`UID_COL_WIDTH`** и т.д. Конфликт с меню дают в первую очередь **три пункта меню** — те же имена, что в старом скрипте.

## Если у вас был «простой» старый Huckster-скрипт

Типичный старый код содержит те же три точки входа, что и меню:

- `function exportHucksterExport() { ... }`
- `function exportHucksterExportRRC() { ... }`
- `function runAllExports() { ... }`
- плюс `runExport`, `fetchAllProducts`, `SHOPS_SET_1` / `SHOPS_SET_2` и т.д.

**Такой файл и новый `huckster-sheets-export.gs` в одном проекте без удаления старого — несовместимы:** имена `exportHucksterExport` и остальные совпадут с новым файлом.

**Что сделать:**

1. Откройте **Расширения → Apps Script**.
2. В файле, где лежит старый Huckster, **удалите целиком** старый блок: от объявления наборов магазинов до конца `fetchAllProducts` / `runExport` (всё, что относится только к старой выгрузке Huckster).
3. **Не трогайте** ваш большой `onOpen` с меню «УПРАВЛЕНИЕ ДАННЫМИ» — он должен остаться **в единственном экземпляре**.
4. Создайте **новый** файл в проекте (например `HucksterExport`) и вставьте **только** содержимое `huckster-sheets-export.gs` из репозитория.
5. Сохраните проект (**Ctrl+S** / **Cmd+S**), вернитесь в таблицу и **полностью обновите вкладку** (F5).

Имена в меню менять не нужно: пункты уже вызывают `exportHucksterExport`, `exportHucksterExportRRC`, `runAllExports` — они объявлены в конце нашего файла.

## Тестовый запуск по одному/нескольким UID

Для быстрой проверки без ожидания полной выгрузки можно запускать функции из редактора Apps Script:

- `runAllExportsTest12461()` — берёт список `hck_TEST_UIDS` в начале файла (сейчас `["12461"]`).
- `runAllExportsForUidList()` — спросит UID в окне prompt, можно вводить `12461` или список через запятую/пробел.

Они пишут в отдельные листы **`Huckster Export TEST`** и **`Huckster Export RRC TEST`**, основные листы не затираются.

## Неправильно

- Вставить новый код **в конец того же файла**, где уже есть старые `exportHucksterExport` / `runAllExports` — получите дубликат функций.
- Держать **две копии** трёх функций в разных файлах — всё равно одна область видимости, ошибка останется.

## Учётные данные

**Файл → Параметры проекта → Свойства скрипта:** `HUCKSTER_EMAIL`, `HUCKSTER_PASSWORD`  
либо раскомментируйте константы в начале `huckster-sheets-export.gs` только у себя (пароли в git не коммитить).
